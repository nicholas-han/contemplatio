个人 Chrome 扩展

让微博安静一点

保留原网页与原内容，用账号规则减少阅读噪音。

阅读方式

仅按发帖账号判断，不调用模型；四个目标账号转发他人的内容仍按目标账号规则处理。可随时展开。

建议先观察至少三个浏览会话，人工检查真实微博后再开启自动模式。

模型连接

不发送 Cookie、登录态或完整网页。首次使用及更换服务域名时，Chrome 会询问该域名的访问权限。未启用时仍可使用本地规则。

连接测试仅发送固定示例文字。获取 TypeSafe API key

四个账号的通用规则

图片识别使用同一 Vercel key，另计模型用量。先判断文字，仅对无实质文字的配图调用看图模型。图表、文字截图、混合内容或看不清的图片保留；一次最多完整判断 9 张图片，更多图片暂保留。不识别视频画面。

通用规则适用于全部四个账号，优先于下方账号规则。未启用图片识别时，无法凭无字配图判断风景或高尔夫。

账号规则

高级阈值

分数为 0–1。规则冲突、媒体信息不足或正文未完整显示时优先保留。价值投资保护优先于灰化和折叠。

本地记录

默认只保存纠错标签、内容哈希和判断信息。开启后原文保存在本机，可导出人工标注；不会自动训练模型或更改规则。未保存的原文无法在离页后恢复。
