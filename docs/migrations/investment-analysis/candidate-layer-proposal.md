# 待决定：旧观测值的接入方式

状态：设计提案，尚未修改当前领域 schema。

旧宇树库有 47 条观测、67 条证据关系；其中 10 个指标有两个来源候选，9 个数值冲突。当前 facts 按自然键保存现值，不保存候选历史。迁移时不能把所有候选依次写入 facts。

## 推荐方案：增加独立的来源候选层

- 当前 facts 和 estimates 的语义保持原样。
- 单独保存来源观测，使用旧库来源标识与 item_id 保证幂等；保留原始数值字符串、比较符、范围、单位、币种、期间、实体范围、指标版本、known_from 和审核状态。
- 来源候选连接迁入的 artifact/evidence，保留同期间所有版本。旧研究项间的证据作用和冲突关系不能被简化成只有支持性链接。
- 推荐视图只提供候选排序与冲突提示，不将“较晚披露”自动解释为正式更正。
- 首次导入不自动推广为 facts。只有可表示的标量值，经选定并记录单位转换后，才进入现值层；不能将大于号、区间或产品价格语义丢掉。
- V4 实体历史、质量问题、研究问题和覆盖记录先随原始数据库及结构化迁移包完整保全，未映射条目必须列出。候选功能不意味着这些模块已全部迁移为可查询的领域功能。

验收：所有 47 条观测可追溯，67 条证据关系有去向，7 个文件哈希一致，10 个双来源序列和9 个冲突保留，重复导入不重复写入，不能影响既有兖矿事实。

## 较小范围的替代方案

先只保留旧数据库和材料作为档案附件，暂不增加候选查询。优点是改动少；代价是宇树结构化数据仍不能通过当前财务查询和 Agent tools 使用。此状态只能称为保全，不能称为完成数据迁移。

## 独立的元数据缺口

40 家公司中只有兖矿匹配当前工作区；39 家拟新增公司没有明确的会计准则字段，中国联通与宇树缺少可直接映射的注册地。后续应从保留披露材料补齐；当前预览不按注册地猜会计准则、不放宽现有必填校验。
