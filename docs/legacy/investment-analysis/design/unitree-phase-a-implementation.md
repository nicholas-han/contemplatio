## 5. 数据质量与下一批缺口

已登记而未掩盖的差异：2026-03-20 招股书与 2026-05-25 上市保荐书对 2024
年营业收入、净利润等数值不同。首批时间序列采用日期更晚的上市保荐书，并建立
开放质量问题；在取得对应更新审计报告后再判定属于会计差错更正、口径更新还是
文件版本差异。

下一批优先级建议：

1. 补齐 2022–2025 完整三表科目，并保存同期间多文档版本，而非覆盖旧值；
2. 抽取分产品收入、销量、售价、客户和渠道维度，建立可复核的业务基础；
3. 跟踪正式发行结果与上市公告，届时再创建证券记录；
4. 扩展产品矩阵，不把当前 G1 示例误当成公司全部产品覆盖。
